## Architecture

A React + TypeScript learning project using TanStack Router (file-based routing) and TanStack Query for data fetching. It displays meals and drinks from two external APIs.

**Entry point flow:** `main.tsx` → `App.tsx` → auto-generated `routeTree.gen.ts` → `RouterProvider`

### Routing (TanStack Router v1 — file-based)

Routes live in `src/routes/` and follow strict naming conventions:
- `__root.tsx` — root layout wrapping all routes
- `route.tsx` — parent layout with `<Outlet />` for nested routes
- `index.tsx` — index route content (e.g., `/meals/`)
- `$paramName.tsx` — dynamic route (e.g., `/meals/$mealId`)

**Important:** `src/routeTree.gen.ts` is auto-generated by the TanStack Router Vite plugin — never edit it manually. It regenerates on every `dev`/`build` run.

Use `createFileRoute('...')` for all new route files. Access params via `Route.useParams()`.

### Data Fetching

`src/utils.tsx` exports two pre-configured Axios instances:
- `customFetch` — TheMealDB (`https://www.themealdb.com/api/json/v1/1`)
- `customFetchDrinks` — boozeapi (`https://boozeapi.com/api/v1/cocktails`)

Use these in TanStack Query `queryFn`s. Validate API responses with Zod schemas.

### Styling

Tailwind CSS v4 via `@tailwindcss/vite` plugin. Support both light and dark mode in all components.

## TypeScript Rules

Strict mode is on (`noUnusedLocals`, `noUnusedParameters`). Avoid `any` — use Zod inference or explicit types instead.
